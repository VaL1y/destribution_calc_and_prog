# Перенос tier_3 на два хоста

Compose из этого каталога — локальная модель. Для двух физических машин нужны
маршрутизируемые адреса между PostgreSQL/repmgr, firewall и TLS/VPN. Docker DNS
работает только внутри одного Docker host, поэтому `REPMGR_NODE_NETWORK_NAME` и
`REPMGR_PARTNER_NODES` должны стать реальными адресами.

FastAPI переносить вместе с БД необязательно. Он принимает списки адресов через
`DB_WRITE_HOSTS`, `DB_READ_HOSTS`, `DB_PORTS`. Это и есть причина отделения
`service` от tier-каталогов.

Для текущего учебного split-brain эксперимента надёжнее сначала использовать
локальные Docker-сети, а межсерверный безопасный failover изучать в `tier_4`.
