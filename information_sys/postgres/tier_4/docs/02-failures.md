# Опыты с отказами ZooKeeper-стенда

Перед каждым опытом записывайте роли через `patronictl list`, время первой ошибки
API, время восстановления и последние подтверждённые события.

## Отказ standby

```bash
docker compose -f compose.remote.yml stop pg-2
docker compose -f compose.remote.yml start pg-2
```

Primary продолжает работу; вернувшийся standby догоняет WAL.

## Отказ leader PostgreSQL

Остановите текущего leader (не полагайтесь на имя `pg-1`). Patroni должен снять
или потерять лидерский lock, выбрать достаточно актуальную replica и повысить её.

## Разрыв между серверами

Удалённая сторона имеет 2/3 ZooKeeper и может сохранить leader. Локальная сторона
с 1/3 не может получить lock и не повышает `pg-3`: split brain предотвращён ценой
недоступности меньшинства.

## Отказ всего удалённого сервера

Локально остаётся 1/3 ZooKeeper. Автоматического promotion не будет. Это
ограничение размещения двух голосов в одном месте; исправление — третий
независимый узел/ЦОД, а не настройка PostgreSQL.
