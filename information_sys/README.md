# Distributed storage labs

Учебный проект сравнивает поведение разных СУБД при репликации, отказах и
сетевых разделениях. Прикладная модель одна: небольшой склад с CRUD и журналом
движений.

- `postgres/` — последовательные уровни PostgreSQL от одной ноды до Patroni.
- `mongo/` — следующий стенд для replica set.
- `redis/` — следующий стенд для primary/replica и Sentinel.
- `cassandra/` — следующий стенд с peer-to-peer репликацией и tunable consistency.
- `legacy/` — прежний пример распределённых вычислений, не относящийся к БД.

FastAPI находится только в `postgres/service` и не является частью конкретного
кластера. Это позволяет менять топологию БД без изменения прикладного кода.
