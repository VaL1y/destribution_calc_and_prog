# Перенос с одной машины на два сервера

Сначала стенд должен заработать локально. Затем единый Compose логически
разделяется, но роли остаются теми же.

## Удалённый сервер

Переносятся:

- `pg-1`;
- `pg-2`;
- `api-remote` для отдельной ветки split-brain-эксперимента.

Каждая PostgreSQL получает отдельный persistent volume и опубликованный только
в приватную сеть порт.

## Локальный сервер

Переносится:

- `pg-3`;
- `api-local` для отдельной ветки split-brain-эксперимента;
- при необходимости Locust и средства наблюдения.

## Что меняется в конфигурации

Имена Docker `pg-1`, `pg-2`, `pg-3` работают только в общей Docker-сети.
Между физическими серверами вместо них потребуются постоянные приватные адреса,
например адреса WireGuard:

```text
10.30.0.11  pg-1
10.30.0.12  pg-2
10.30.0.21  pg-3
```

В конфигурации repmgr должны быть именно адреса, достижимые со всех трёх нод.
Понадобятся соединения:

- PostgreSQL/repmgr: TCP 5432 между участниками;
- SSH не обязателен для обычного failover, но может понадобиться отдельным
  административным операциям repmgr;
- FastAPI должен видеть все три адреса для multi-host подключения.

Публично открывать PostgreSQL нельзя. Сначала строится приватная сеть и правила
firewall, затем создаются volumes и только после этого запускаются контейнеры.

## Известная модель отказа

После переноса `pg-1` и `pg-2` всё ещё находятся на одной физической машине.
Отказ отдельного процесса переживается хорошо. При отказе всей удалённой машины
остаётся только `pg-3`, и мы разрешаем ей promotion ради доступности.

При сетевом разделении это способно создать два primary. Когда появится третий
независимый сервер, есть два пути:

1. перенести туда `pg-2`, чтобы три data-ноды оказались в трёх failure domain;
2. перейти на Patroni и разместить три DCS-голоса независимо от PostgreSQL.

Отдельные Compose-файлы для серверов пока не созданы: их адреса, ОС, способы
доступа и каталоги volumes ещё неизвестны. Делать фиктивную «готовую» сетевую
конфигурацию до этого шага было бы опаснее, чем заполнить её вместе после
локальной лабораторной работы.
